# Interview Prep Lab — Allied Softech

Static site (HTML5, CSS3, vanilla JS, Tailwind CSS). No backend, no database.

**Open `index.html`** in a browser (or serve the folder with any static server). Progress is saved in LocalStorage.

- 326 questions: 120 Technical, 150 DSA, 30 Loops, 26 HR (IDs `TECH-001…`, `DSA-001…`, `LOOP-001…`, `HR-001…`)
- `data/*.js` are generated from the Markdown sources in `tools/source/` — run `npm install && npm run build` to regenerate data and Tailwind CSS
- `js/` modules: store (state + LocalStorage), data (index/search), markdown (renderer + highlighter), effects (stars, cursor, toasts), ui, views, guides
- Shortcuts: `Ctrl+K` or `/` search · `←` `→` previous/next · `L` learned · `B` bookmark
