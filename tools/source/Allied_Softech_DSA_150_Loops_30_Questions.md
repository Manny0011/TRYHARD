## Purpose

Standalone question data file for the Interview Prep Lab website.

## Question Count

- DSA: **150**

- Total: **180**

## 🎯 Company-Focused Preparation

This set targets fresher/entry-level software preparation with practical coding and foundational problem-solving. The DSA mix is intentionally **Easy → Medium** and emphasizes arrays, strings, hashing, searching, sorting, linked lists, stacks/queues, basic trees/graphs, and practical STL/priority-queue style problems rather than very advanced competitive-programming questions.

Available candidate-reported Allied Softech interview information has mentioned project discussion, in-depth OOP concepts, STL, a coding question and an SQL query for a C++ developer interview. This question set is therefore designed to support that type of screening alongside the separate Technical question file.

This is a preparation strategy based on reported interview experiences, not an official company syllabus.
